# OBDeleven VAG 0.107.1 PRO Patched

Patched version of OBDeleven VAG 0.107.1 with PRO subscription forced locally.

## Patches applied
- `SubscriptionType.isPaid()` always returns true
- `SubscriptionType.fromString()` always returns PRO

## Files
The patched XAPK is large (~51 MB). Due to upload limits on this interface, the full binary may need to be added via GitHub Releases or by cloning and pushing locally.

### How to use
1. Obtain the patched XAPK (base APK + arm64 + xxhdpi splits)
2. Open in AntiSplit-X to merge into a single APK
3. Uninstall the original app
4. Install the merged/patched APK

Repo created for the patched build.
